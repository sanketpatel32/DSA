# DSA — Data Structures & Algorithms in Python

**236 problems** organized across **30 categories**, arranged in a deliberate learning order.

## 📚 What's Inside

- **236 Python files** (`001_*.py` … `236_*.py`), one per problem.
- Each file has a docstring with the **Question**, **Sample Input/Output**, **Expected Time/Space Complexity**, and **all meaningful Approaches** (with their complexities).
- A complete **[`000_Python_DSA_Guide.md`](000_Python_DSA_Guide.md)** — an 18-section modern Python reference (data structures, `collections`, `heapq`, `bisect`, `itertools`, bit manipulation, Big-O tables, common patterns, and pitfalls).
- An indexed **[`000_list.md`](000_list.md)** with every problem hyperlinked and grouped by category.

## 🚀 How to Use

1. Open [`000_list.md`](000_list.md) and pick a problem.
2. Click the link to open the `.py` file.
3. Read the **Question**, **sample I/O**, and **Approaches** in the docstring.
4. Implement your solution below the docstring.
5. Refer to [`000_Python_DSA_Guide.md`](000_Python_DSA_Guide.md) for Python idioms.
